# templates/

회사 PPT 템플릿, Word 양식, 브랜드 자산 파일을 여기에 보관합니다.

- `*.pptx`, `*.docx`, `*.key` 파일은 `.gitignore`에 의해 추적되지 않습니다 (회사 소유, 외부 공유 금지).
- 이 `README.md`와 `.gitkeep`만 git으로 관리됩니다.

## 사용법

제안서 작성 시 이 디렉터리의 템플릿을 Claude Code 스킬에 전달합니다:

```
templates/회사템플릿.pptx 의 레이아웃을 사용해서 drafts/제안서.md 를 PPT로 만들어줘.
```

자세한 워크플로는 [`GUIDE.md`](../GUIDE.md) §4, §5-1을 참고하세요.
